# gsoc-technical-blog

This repository contains technical short articles written by cybersecurity
persons at CGI. It aims at sharing with the general public some findings on
ongoing malware campaigns.

Topics :

* Malware Analysis
* Digital Forensics
* Incident Response
* Breaking Things
* Dangerous Hacks
* Threat Intelligence
* Threat Research
* Alert Handling
* SOC operations

Visit https://www.cgi.com/en/cybersecurity to know more about CGI cybersecurity services.
